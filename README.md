# SQL Theory Trainer

Тренажёр по теории SQL: 30 вопросов (15 теории + 15 практики) с проверкой, пояснениями и разбором ошибок.

Статический сайт без сборки и зависимостей — подходит для GitHub Pages.

## Возможности

- три режима: все вопросы / только теория / только практика;
- перемешивание вопросов;
- мгновенная проверка ответа с пояснением;
- прогресс и карта вопросов;
- экран результата с процентом, разбивкой по теории и практике и разбором ошибок;
- повтор только неверно отвеченных вопросов;
- сохранение прогресса в `localStorage`;
- тёмная и светлая темы;
- управление с клавиатуры: `1`–`4` — выбор варианта, `Enter` — проверить / далее.

## Структура

```
sql_theory_trainer/
├── index.html          # разметка всех экранов
├── css/
│   └── style.css       # темы, вёрстка, адаптив
├── js/
│   ├── questions.js    # банк вопросов и тестовые данные
│   └── app.js          # логика тренажёра
├── .nojekyll           # отключает обработку Jekyll на GitHub Pages

```

## Запуск локально

Открыть `index.html` в браузере или поднять простой сервер из корня проекта:

```bash
python -m http.server 8000
```

и перейти на `http://localhost:8000/sql_theory_trainer/`.

## Публикация на GitHub Pages

1. Закоммитить и запушить папку `sql_theory_trainer` в репозиторий.
2. В репозитории: **Settings → Pages**.
3. Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
4. Сайт будет доступен по адресу `https://<user>.github.io/<repo>/sql_theory_trainer/`.

Альтернативно можно положить содержимое папки в корень репозитория или в `docs/`.

## Как добавить вопросы

Вопросы лежат в `js/questions.js` в массиве `questions`:

```js
{
  id: 31,
  kind: 'theory',            // 'theory' или 'practice'
  tag: 'Теория',
  topic: 'Нормальные формы',
  prompt: 'Текст вопроса',
  dataset: 'studentHobbyRu', // необязательно
  sql: 'SELECT ...',         // необязательно
  options: ['A', 'B', 'C', 'D'],
  correct: [1],              // индексы верных вариантов
  explanation: 'Почему так'
}
```

Если верных вариантов несколько, перечислить все индексы в `correct`.
